# Abha Visitor Guide

## What it does

It takes a visitor's Abha interests and trip preferences and gives a bilingual list of matching destinations or a browser-saved day itinerary.

## Who it is for

Visitors to Abha who want a simple guide for nature, cafés, food, heritage, photography, family outings, and approved adventure destinations.

## Needs

Nothing but a modern web browser. No account, API key, database, server, or internet connection is needed to use the guide; internet is only needed if a visitor chooses to open a supplied Google Maps link.

## How to run it

### Windows

1. Download the repository from GitHub and extract it.
2. Open the extracted project folder.
3. Double-click `index.html`.

No `py` or Python command is needed.

### Mac

1. Download the repository from GitHub and extract it.
2. Open the extracted project folder.
3. Double-click `index.html`.

No `python3` or Python command is needed.

## Try it with the sample data

1. Open `index.html`.
2. Select **Saved trip / الرحلة المحفوظة**.
3. Select **Load example / تحميل مثال**.
4. You should see a made-up example plan using Family, Nature, Half day, 100–300 SAR, and Moderate walking.

The local example destination data is loaded from `sample-data/data.js`. It includes no people, phone numbers, or ID numbers. The guide creates a plan in the browser only and does not produce a downloadable file.
